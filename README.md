# CASHMACHINE — витрина финансовых продуктов

Статичный сайт + админка. Ничего собирать не надо: залил папку на хостинг — работает.
Из требований к хостингу только PHP (есть на любом шаред-хостинге).

Витрина финансовых продуктов: кредитные и дебетовые карты, займы и МФО, кредиты
наличными, РКО. У каждой карточки кнопка «Оформить» (ведёт на страницу банка по
партнёрской ссылке) и «Скопировать ссылку» рядом.

Публичная часть — обычный каталог для того, кто выбирает продукт. Вознаграждение
(`payout`, `payFor`) на витрину **не выводится**: эти поля видны только в админке.

> Ссылки в `data.js` — заглушки на официальные страницы банков. Перед запуском
> замени их на свои партнёрские: именно по ссылке считается выплата.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | сама витрина |
| `admin.html` | панель управления: категории, офферы, статусы |
| `styles.css` | все стили, одна тема |
| `app.js` | логика витрины: фильтры, поиск, копирование ссылок, форма |
| `admin.js` | логика админки |
| `data.js` | каталог. Его переписывает админка при публикации |

| `.htaccess` | закрывает служебные файлы, включает сжатие |
| `fonts/` | шрифты лежат рядом, к Google не ходим |

## Заливка на хостинг

1. Скинь всё содержимое папки в корень сайта (`public_html`, `www` — как у хостера называется).
2. Переименуй `config.sample.php` в `config.php` и поменяй пароль:

   ```php
   'password'  => 'сюда_свой_пароль',
   ```

3. Дай права на запись файлу `data.js` — иначе админка не сможет сохранять. В файловом
   менеджере хостинга это «Права доступа» → `664` (или `666`, если `664` не хватит).
4. Проверь: открой `твойсайт.ру/api.php?action=ping` — должно ответить `{"ok":true,...}`.
   Если `"writable":false` — вернись к пункту 3.
5. Заходи в `твойсайт.ру/admin.html`, вводи пароль и правь витрину.

## Как править витрину

Всё в `/admin.html`:

- **Категории** — добавить, переименовать, удалить. При удалении категории офферы из неё
  переносятся в другую, на выбор. Категория «Все» не удаляется, это общий фильтр.
- **Офферы** — добавить, изменить, удалить, поменять порядок стрелками.
- **Условия продукта** — у каждого оффера свой список пар «условие — значение»
  («Без процентов» → «120 дней», «Сумма» → «до 100 000 ₽»). До шести пар, порядок
  как в форме. Так одна и та же карточка подходит и кредитке, и займу, и РКО.
- **Выплата** — сумма и «за что платят». Внутреннее поле: на сайте его нет,
  видно только в редакторе.
- **Пауза** — переключатель «Активен» в карточке оффера. Выключил → на сайте карточка
  становится серой, кнопки «Оформить» и «Скопировать ссылку» пропадают. Оффер при этом
  остаётся на витрине, просто с пометкой «На паузе».
- **Опубликовать** — сохраняет каталог на сервер. До нажатия все правки лежат черновиком
  в твоём браузере, сайт их не показывает.

Рядом с редактором — живой предпросмотр: видно, как витрина выглядит с правками.

Перед перезаписью `data.js` бэкенд кладёт копию в `data.backup.js`. Если что-то удалил
не то — переименуй копию обратно в `data.js`.

## Заявки

Заявки с формы всегда пишутся в `leads.csv` рядом с сайтом (открывается Excel'ем,
кириллица не ломается). Файл закрыт от посторонних через `.htaccess`.

### Заявки в Google-таблицу

1. Создай таблицу, первая строка — шапка: `Дата`, `Имя`, `Контакт`, `Источник`, `Комментарий`.
2. `Расширения` → `Apps Script`, вставь:

   ```js
   function doPost(e) {
     var d = JSON.parse(e.postData.contents);
     SpreadsheetApp.getActiveSheet().appendRow([
       d.date, d.name, d.contact, d.source, d.comment
     ]);
     return ContentService.createTextOutput('ok');
   }
   ```

3. `Развернуть` → `Новое развёртывание` → тип **Веб-приложение**,
   «Выполнять от имени» — от своего аккаунта, «У кого есть доступ» — **у всех**.
4. Скопируй выданный адрес и вставь в `config.php`:

   ```php
   'sheet_url' => 'https://script.google.com/macros/s/.../exec',
   ```

Всё, заявки падают в таблицу и дублируются в CSV.

```bash
php -S 127.0.0.1:4470 -t /Users/openclaw/executtr-vitrina
```

Открыть `http://127.0.0.1:4470/`. Админка — `http://127.0.0.1:4470/admin.html`.
Пароль по умолчанию — `executtr`.

## Если PHP на хостинге нет

Витрина всё равно работает — она читает `data.js` напрямую. Админка в этом случае
переходит в офлайн-режим: правки хранятся в браузере, а кнопка «Опубликовать»
превращается в «Скачать data.js» — скачал файл и залил его на хостинг руками.
